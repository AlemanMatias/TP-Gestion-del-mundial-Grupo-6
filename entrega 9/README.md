# Entrega 9

Aplicación ABM de Jugadores
Requisitos
Python 3.10 o superior (https://www.python.org). Al instalar, marcar "Add Python to PATH".
ODBC Driver 17 o 18 for SQL Server (https://learn.microsoft.com/sql/connect/odbc/download-odbc-driver-for-sql-server).
Base Mundial2026 creada y con datos, ejecutando en SSMS (modo SQLCMD) primero RECREAR_BASE.sql y luego JUEGO_DE_DATOS.sql.


Configuración (cada integrante, en su computadora)
Abrir app.py con el Bloc de notas o VS Code y modificar solo estas líneas del inicio:

python
SERVIDOR = r"localhost\SQLEXPRESS02"   # <- poner el nombre de TU servidor SQL
BASE_DE_DATOS = "Mundial2026"
USUARIO = ""                           # vacío = autenticación de Windows
CONTRASENIA = ""

Instalación (una sola vez por computadora)
Instalar las librerías:
pip install -r requirements.txt

Ejecución
Opción fácil: doble clic en iniciar_app.bat.
